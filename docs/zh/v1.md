# 从 v1 迁移

> 下一次主版本引入了破坏性变更. 本指南对每一处变更给出 Before/After 对照, 让 v1 代码库一次迁移到位.

如果你是新接入, 请跳过本页, 直接看 [快速开始](./guide/getting-started.md).

## 概览

v1 to v2 重写将 `OhNetBuilder` 改名为 `OhNetClient`, 并整合状态所有权. 库现在严格不可变: 每次配置调用都返回新实例, 客户端每个字段都是 `readonly`, 调度器改写 caller-provided context 而非触碰客户端.

四处变更面:

- **类与构造器** - `OhNetBuilder` to `OhNetClient`; `new ...(config)` to `OhNetClient.create(config)`
- **`fork` 签名** - 接收 4 字段 options 对象, 代替 `OhNetConfig`
- **中间件与事件查询** - `get middleware()` / `get event()` getter 替换为 `middlewares()` / `events()` 方法
- **类型重命名** - `OhNetMiddlewareBuilder` / `OhNetEventBuilder` 已移除; 替换为 `OhNetMiddlewareQuery` / `OhNetEventQuery`

其余 (`with` / `clean` / `on` / `off` / `append` / HTTP verbs / `request`) 保持原签名与行为不变.

## 快速清单

按这个清单逐条处理; 每条都链到下方对应章节.

- [ ] 把 `import { OhNetBuilder }` 替换为 `import { OhNetClient }`
- [ ] 把每个 `new OhNetBuilder(config)` 替换为 `OhNetClient.create(config)`
- [ ] 把 `client.middleware.list()` / `.has()` / `.get()` 替换为 `client.middlewares().list()` / `.has()` / `.get()`
- [ ] 把 `client.event.list(event?)` 替换为 `client.events().list(event?)`
- [ ] 如果你 import 过 `OhNetMiddlewareBuilder` / `OhNetEventBuilder` 类型, 改用 `OhNetMiddlewareQuery` / `OhNetEventQuery` (注意: 不再从公开入口导出)
- [ ] 更新 jsdoc 中指向 `reference/builder.html` 的 `@see` 链接 - URL 已迁移到 `reference/client.html`

## 类与构造器

公开类重命名, 构造器现在私有. 构造走静态工厂方法.

**Before (v1)**

```ts
import { OhNetBuilder } from "@xtwis/ohnet"

const client = new OhNetBuilder({
  url: "https://api.example.com",
  adapter: myAdapter,
  headers: { "x-app": "demo" },
})
```

**After (v2)**

```ts
import { OhNetClient } from "@xtwis/ohnet"

const client = OhNetClient.create({
  url: "https://api.example.com",
  adapter: myAdapter,
  headers: { "x-app": "demo" },
})
```

`OhNetConfig` 未变; 仅调用形态不同.

## `fork` 签名

`fork` 不再接收 `OhNetConfig`. 它接收一个 4 字段可选的 options 对象; 每个未传字段沿用原值.

**Before (v1)**

```ts
const v2 = client.fork({ url: "/v2", headers: { "x-version": "2" } })
```

**After (v2)** - 通过 options 对象替换 middleware / event / adapter / context:

```ts
// Replace the middleware list outright
const stripped = client.fork({ middlewares: [] })

// Replace the event registry outright
const quiet = client.fork({ events: new Map() })

// Swap the transport
const grpc = client.fork({ adapter: grpcAdapter })
```

请求相关字段 (`url`, `headers`, `params` 等) 用 `add(config)` 代替 `fork`.

`fork` 默认按值拷贝原实例的 `middlewares` 和 `events`, 所以即使空 `fork()` 调用也会产生一个可独立变更的新实例.

## 中间件与事件查询

单数 getter 改为方法. 返回类型从 `OhNetMiddlewareBuilder` / `OhNetEventBuilder` 改为只读的 `OhNetMiddlewareQuery` / `OhNetEventQuery`.

**Before (v1)**

```ts
client.middleware.list() // => OhNetMiddleware[]
client.middleware.has("auth") // => boolean
client.middleware.get("auth") // => OhNetMiddleware | undefined

client.event.list("on_start") // => readonly OhNetEventHandler[]
client.event.list() // => readonly OhNetEventHandler[] (all events)
```

**After (v2)**

```ts
client.middlewares().list() // => readonly OhNetMiddleware[]
client.middlewares().has("auth") // => boolean
client.middlewares().get("auth") // => OhNetMiddleware | undefined

client.events().list("on_start") // => readonly OhNetEventHandler[]
client.events().list() // => readonly OhNetEventHandler[] (all events)
```

每次调用返回新的快照; 对 query 的修改不会回传到客户端.

`OhNetEventQuery.get(event)` 是**新增**方法 - 返回 `readonly OhNetEventHandler[] | undefined`, `undefined` 表示该事件无注册 handler. (v1 中, 事件注册表没有暴露 `get`.)

## 类型重命名

| v1                       | v2                     |
| ------------------------ | ---------------------- |
| `OhNetBuilder`           | `OhNetClient`          |
| `OhNetMiddlewareBuilder` | `OhNetMiddlewareQuery` |
| `OhNetEventBuilder`      | `OhNetEventQuery`      |

`OhNetMiddlewareQuery` 和 `OhNetEventQuery` 在 v2 中是**内部**类型 - 它们不再从公开入口重新导出. 如果你的代码引用它们, 改用 `middlewares()` / `events()` 返回的内联结构类型 (一个含 `get` / `has` / `list` 的结构类型), 而不是 import 具名 class.

```ts
// v1
//   import { OhNetBuilder, OhNetMiddlewareBuilder } from "@xtwis/ohnet"
//   const b: OhNetMiddlewareBuilder = client.middleware

// v2
//   import { OhNetClient } from "@xtwis/ohnet"
const q = client.middlewares() // structural type, no name import needed
const list = q.list() // readonly OhNetMiddleware[]
```

## 未变更项

这些 API 在 v1 和 v2 之间完全一致:

- `with(middleware)` 与 `clean(name)` - 同名, 同样的替换语义, 同样抛 `OHNET_MIDDLEWARE_NAME`
- `on(event, callback)` 与 `off(event, target)` - 同样的注册顺序, 同样的引用相等性移除
- `append(path)` - 同样的 URL 拼接, 同样不插入分隔符
- 所有 HTTP verbs (`get` / `post` / `put` / `delete` / `patch` / `head` / `options`) - 同签名, 同参数形态
- `request<T>(config?)` - 同 per-request overrides 契约; 用户视角行为不变
- `OhNetMiddleware`, `OhNetEventHandler`, `OHNET_EVENT`, `OHNET_ERROR_CODE` 常量与类型 - 未变

如果你的 v1 代码只用这些, 在 import 重命名后无需任何改动.
